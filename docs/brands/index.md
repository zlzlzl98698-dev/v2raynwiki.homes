## 数据分级与透明说明

- **含实测截图（Measured Data）**：收录有 2026-08-11 统一批次 `MAI-TEST-BOT` 原始 PNG/JPG 测速图，或 2026-08-19 三网 2Gbps / 珠海联通 9Gbps 实测截图（例如 [光速云深度评测](/reviews/guangsuyun)）。
- **品牌资料整理（Vendor Data）**：依据品牌公开介绍与套餐说明整理，尚未取得本站独立晚高峰实测截图，相关宣传语均标注来源属性。
- **部分待核实 / 历史档案**：如宇宙云缺少完整当期套餐表，灵动云、浪网、边缘节点 EdgeNova 源自 2026-08-09 历史库，已明确提示核验边界。
