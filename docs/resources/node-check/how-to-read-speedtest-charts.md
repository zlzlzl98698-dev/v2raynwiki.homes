## 一、测速表核心字段逐列拆解

| 字段名称 | 物理含义 | 实用判断阈值 |
| --- | --- | --- |
| **类型（Protocol）** | 该次测速实际使用的加密协议（Shadowsocks / VLESS / Trojan / AnyTLS） | 用来核对商家宣传协议与实际下发协议是否一致 |
| **TLS RTT** | 完成一次加密数据交换的往返延迟（毫秒） | 港台 ≤ 50ms、日新 ≤ 80ms、美西 ≤ 180ms 属优秀区间 |
| **HTTPS 延迟** | 模拟真实打开 HTTPS 网页的一次完整请求体感延迟 | 数值越低网页首屏越快；若远高于 TLS RTT 3 倍以上通常意味着出口排队或 DNS 偏慢 |
| **IPType / IPRisk** | 落地 IP 属于机房商宽还是住宅，以及欺诈风险分（LOW/MEDIUM） | 访问 AI、银行与电商时，IPRisk 越低越不易弹验证码 |
| **平均速度 / 最高速度** | 测速窗口内的稳定吞吐均值与瞬时峰值（注意单位 MB/s × 8 = Mbps） | 看 4K 视频单节点稳定 **15 MB/s（120 Mbps）** 以上即已非常流畅 |
| **每秒速度曲线** | 反映带宽是否平直稳定 | 平直饱满优于忽高忽低的锯齿曲线 |
| **UDP 类型** | `FullCone` / `RestrictedCone` / `Unknown` | 游戏联机、语音通话与 Hysteria/QUIC 优先选 `FullCone` |

## 二、真图实战演示：看懂光速云 9Gbps 与三网 2Gbps 截图

以本站收录的 [光速云深度评测](/reviews/guangsuyun) 原始截图为例：

1. **看底部状态栏**：清晰标明 `主端=4.3.3 / 喵速=SC-2.3.1 (A-长沙电信@2Gbps), 线程=6` 或 `珠海联通 9Gbps单线程`。注意**单线程能跑出 300+ MB/s 的含金量远高于 32 线程堆出来的总速度**。
2. **看解锁列细节**：图上直接用颜色区分解锁地域，例如香港节点在 OpenAI 一列显示橙色 `仅APP(HK)`、Gemini 一列显示红色 `失败`，而新加坡节点全绿显示 `解锁(SG)`——这比商家口头一句“完美支持 AI”真实得多。
3. **看异常项是否被隐藏**：在珠海联通 9Gbps 截图中，尽管 60+ 节点表现强劲，但第 36 行 `美国02` 节点仅跑出 `1.60 KB/s`。保留这类真实异常才是一份可信的实验室报告。

## 三、识别测速图常见的 4 个误区

- **误区 1：把 `MB/s` 和 `Mbps` 混为一谈**。`1 MB/s = 8 Mbps`，截图里显示 `50 MB/s` 等同于 `400 Mbps`。
- **误区 2：拿凌晨 01:00 的满速当晚高峰体验**。晚间 20:00–23:00 是跨国公网出口最拥堵的时段，中转机场在此时常出现断崖掉速，IEPL/IPLC 专线的真正价值正在晚高峰体现。
- **误区 3：只看广东联通机房跑分**。广东联通直连香港物理距离极短，北方移动/电信用户的实际延迟通常会高出 20–50ms，因此跨三网测试尤为重要。
- **误区 4：忽略“送中(CN)”标记**。若 YouTube 列显示 `送中(CN)`，说明该落地 IP 被 Google 地理定位回中国大陆，可能导致无法使用 YouTube Music 或部分地区版权内容。

## 四、深入实析：结合 2026-08-11 与 2026-08-19 实测库做跨网对比

本站同时保留了两种完全不同维度的实测证据，学会交叉阅读这两类截图，就能避开单一数据带来的判断偏差：

### 1. 同一品牌跨三大运营商的吞吐稳定性差异
以 [光速云 2026-08-19 2Gbps 实测](/reviews/guangsuyun) 为例，同一组 62 个节点在长沙电信、广西移动与河北联通下呈现出明显规律：
- **香港专线（20 个节点）**：在长沙电信（35–42 MB/s，TLS RTT 20–31ms）与广西移动（最高 52.04 MB/s，TLS RTT 23ms）均保持高吞吐低延迟；在河北联通样本中均速降至 22–36 MB/s 且部分节点 HTTPS 延迟升高，直观反映了北方跨省接入南方入口的真实物理跳数影响。
- **新加坡与日本节点**：三网普遍维持在 32–53 MB/s 区间，其中新加坡在全部三个运营商下均解锁 Gemini，而日本在三个运营商下均解锁 OpenAI、Netflix 与 Disney+。

### 2. 单线程极限测试（9Gbps）vs 多线程并发测试（32 线程）
在 2026-08-11 `MAI-TEST-BOT` 统一批次中，多数截图采用 32 线程并发测速；而 2026-08-19 珠海联通 9Gbps 批次采用了 **单线程（线程=1）** 对 VLESS 节点进行极限吞吐摸底。对终端用户来说：
- **单线程跑分**直接决定你下载一个大文件或播放 4K HDR 视频的流畅度；
- 只要单线程实测均值达到 **15 MB/s（120 Mbps）** 以上，就已经能覆盖 99% 家庭宽带的极限需求；单线程跑出 300–420 MB/s（2.4–3.3 Gbps）则证明服务端单机出口带宽冗余极度充裕。

### 3. 自检本机到机场节点的真实单线程链路
你无需安装复杂的 Bot 工具，在本地电脑开启代理后用一行 `curl` 即可复现精确到毫秒的 DNS、TCP、TLS 与首包 TTFB 分段耗时：

```bash
curl -o /dev/null -s -w "DNS解析: %{time_namelookup}s\nTCP连接: %{time_connect}s\nTLS握手: %{time_appconnect}s\n首包TTFB: %{time_starttransfer}s\n平均速度: %{speed_download} B/s\n" https://speed.cloudflare.com/__down?bytes=25000000
```

## 五、测速后端防造假核查表与实操复现方案

互联网上流传的机场推广测速图良莠不齐，部分推广图存在「只测凌晨 3 点带宽、截去底部参数栏、甚至用本地局域网环回测试充当跨境速度」的乱象。作为普通读者，阅读任何一份外部测速报告时，可按以下 5 条审计清单逐一核验其真实含金量：

| 核查项目 | 可信基准表现 | 常见猫腻 / 造假手法 |
| :--- | :--- | :--- |
| **底部信息条完整度** | 保留客户端/Bot 版本、测试点运营商及物理上限（如 `长沙电信@2Gbps`、`珠海联通 9Gbps`）、线程数与测试时间 | 裁剪底部状态栏，仅截取中间速度亮丽的绿色条状图，隐藏实际测试时间为凌晨低谷或多线程叠加 |
| **线程数与并发策略** | 标注 `线程=1`（单线程极限）或合理并发（`线程=4/6`）；单线程跑分对实际日常浏览与视频最具参考意义 | 使用 `32` 线程甚至 `64` 线程暴力并发，把每条限速 5Mbps 的普通公网节点硬凑出 160Mbps 账面峰值 |
| **异常与失败行保留** | 诚实保留 1–2 个超时、仅 APP 解锁、或仅几 KB/s 的真实异常节点（例如光速云 9Gbps 图保留了 `美国02` 异常行） | P 图抹除超时行或只勾选 5 个最快的香港节点生成拼图 |
| **TLS RTT vs HTTPS 延迟比值** | HTTPS 延迟约为 TLS RTT 的 `1.5×–2.5×` 属正常握手开销区间 | TLS RTT 很低（30ms）但 HTTPS 延迟飙升至 `900ms+`，说明落地出口严重拥堵或远端服务器高负载排队 |
| **IPRisk / 送中标识透明度** | 如实标出 `解锁(SG)`、`仅APP(HK)`、`失败` 与 `送中(CN)` | 模糊打码解锁列或用过时半年前截图顶替当前状态 |

### 实测脚本验证补充（流媒体/AI 与 ASN 落地核查）

测速图中的 `IPRisk` 与流媒体解锁列并不是一成不变的静态属性，机场上游随时可能更换落地 VPS。在完成订阅导入并选中任意节点后，建议除了上文的 `curl` 下行测速外，再执行两条轻量级 CLI 命令核实当前节点的真实出口 ASN 与 DNS 是否泄漏：

```bash
# 1. 查询当前代理节点出口 IP、运营商 ASN 组织与地理位置
curl -s --max-time 8 https://ipinfo.io/json

# 2. 检查当前系统 DNS 解析出口是否与代理节点同地区（防止国内 DNS 泄漏导致 AI 风控）
curl -s --max-time 8 https://edns.ip-api.com/json
```

如果在终端返回的 `ipinfo.io/json` 结果中，`country` 显示 `HK`（香港）却在尝试访问 Google Gemini，或者 `org` 归属显示大型公有云且同时间多个品牌返回完全相同的网段（参考 [31 家机场风控审计](/resources/risk-intel/31-brands-audit-summary) 中提到的同上游特征），就能够解释为什么「测速图明明全绿、实际使用却频频弹验证码或被拒访问」。

## 七、常见问题（FAQ）

### 1. 测速图里的“平均速度”和“最高速度”应该看哪一个？
优先看“平均速度”以及右侧的每秒速度柱状曲线。如果最高速度很高但均速很低、柱状图呈剧烈锯齿或后半段断崖下跌，往往代表线路存在突发限速或晚高峰丢包。

### 2. 为什么不同机场的 2026-08-11 测速图不能直接拿来排绝对名次？
因为不同品牌测试时间跨越凌晨、白天与晚高峰，且部分品牌使用 5Gbps/32 线程工具，另一些使用 9Gbps/单线程或不同协议，测试条件并不完全受控，仅适合作为节点连通性与区间能力参考。
