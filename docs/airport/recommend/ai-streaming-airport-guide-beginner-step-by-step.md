## 三、新手处理「支持ChatGPT和Netflix的机场」最易忽略的细节

1. **导入订阅后忘记点击激活卡片**：在 Clash Verge Rev 的「订阅（Profiles）」界面导入链接后，必须**单击生成的卡片使其高亮**，再去「代理」页选择「规则（Rule）」模式。
2. **长期误开全局（Global）模式**：全局模式会把微信、B 站、淘宝与网盘流量全部绕去海外，既卡顿又白白耗尽流量；日常请始终保持 **规则（Rule）** 模式。
3. **香港节点直连 AI 报错以为配置失败**：如 [光速云档案](/reviews/guangsuyun) 所示，香港节点普遍对 ChatGPT 网页版与 Gemini 存在地区限制，使用 AI 工具时请切换至 **新加坡、日本或美国节点**。

## 机场推荐新手入门原理：从订阅导入到规则放行

刚接触「支持ChatGPT和Netflix的机场」的读者常有一个核心困惑：**“为什么一个不到 100 字符的订阅 URL 能瞬间变成几十个各国节点？”** 本质上订阅链接是一个托管在 CDN 上的 YAML/Base64 动态配置文件，由客户端定期拉取最新的入口域名、加密端口与分流规则集。

### 零基础上线前必须做对的 3 个动作

1. **只从开源仓库正版 Release 下载客户端**：切勿通过不明百度网盘或第三方广告站下载改包程序；桌面端确认校验签名或官方主页链接。
2. **区分「系统代理」与「TUN 虚拟网卡」**：浏览网页只开「系统代理（Rule 模式）」即可；如果 Terminal、Git、Docker、Cursor 报超时，再打开 Service Mode 与 TUN 开关。
3. **订阅导入前先校准操作系统时钟**：确保 Windows / macOS 开启自动对时，否则节点测速绿字也会因时间戳偏差超过 90 秒而被服务端直接断开。

### 一键验证本地订阅是否已真正接管出站

```bash
# 运行以下两条命令，分别检查代理链路真实出口 IP 与连通状态码
curl -I -s https://www.google.com | head -n 5
curl -s https://api.ip.sb/geoip
```

<details open class="kb-faq-details">
<summary><strong>3. 为什么同一家机场不同地区节点的 ChatGPT 与 Gemini 可用性完全不同？</strong></summary>

OpenAI 与 Google 对机房 ASN 归属和地区政策采用独立风控。例如实测显示香港专线节点对 OpenAI 常仅支持移动端 App，且 Gemini 在香港普遍不可用；切换至新加坡或日本/美国节点即可解决。

</details>

<details open class="kb-faq-details">
<summary><strong>4. 选机场时“不限设备数量”有没有隐性限制？</strong></summary>

绝大多数主流机场允许家庭自有设备多端同时在线，但若把订阅链接公开分享、同时从几十个不同省市 IP 并发请求，仍会触发面板的防共享滥用审计。

</details>

<details open class="kb-faq-details">
<summary><strong>5. 首次下单买哪一档最稳妥？</strong></summary>

优先选购 19–25 元常规月付档（例如光速云极速版 ¥25/168GB、唯兔云 ¥19.9/150GB 或一翻云 ¥20/150GB），在自家宽带晚高峰连续测试一周后再考虑年付或永久流量包。

</details>
