## 重要安全与维护状态提醒

1. **只从官方渠道下载**：搜索引擎置顶结果常出现山寨中文站捆绑广告甚至木马。务必直接核对 GitHub 官方 Release 仓库或对应地区官方 App Store。
2. **注意停更与第三方劫持风险**：
   - `Mihomo Party` 请关注仓库维护动态，不建议未经核对就当作默认首选；
   - `NekoBox for Android` 官方已明确警告**切勿安装 Google Play 上被第三方控制的同名版本**，仅从 GitHub Releases 获取 APK。
3. **购买机场前核对客户端模式**：像飞猫云、Firefly、SOGO 云、隐形人等采用专属客户端且不提供第三方订阅；如果你需要使用 Clash Verge Rev、Shadowrocket 或 OpenWrt，请优先选择支持通用订阅的品牌（如 [光速云](/reviews/guangsuyun)、[一翻云](/brands/yifan)、[星岛梦](/brands/xingdaomeng)）。
