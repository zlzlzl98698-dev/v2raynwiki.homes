## Clash 使用教程跨平台底层网络栈与统一规范化策略

Windows（WinHTTP / 注册表代理 / Wintun）、macOS（NetworkExtension / utun）、Android（VpnService 进程锁保活）、iOS（NEPacketTunnelProvider 15MB 内存上限）与 OpenWrt（fw4 nftables + TProxy/TUN）五类环境的底层差异很大，但规则层面应该尽可能集中统一维护。

### 跨终端迁移 4 项工程准则

1. **订阅规则集中托管**：把所有分流规则写入全局可扩展配置或统一远程规则集，不要在 Windows 写一套、到 Shadowrocket 又手工拼凑另一套导致不同步。
2. **注意 iOS 15MB 内存墙限制**：给 iPhone / iPad 配置规则时避免塞入数十万行臃肿的 GEOSITE 全量域名表，优先加载精简后的核心 AI 与流媒体分组列表。
3. **路由器旁路与桌面终端避免双重代理**：当客厅 OpenWrt 已经接管透明代理后，局域网内的 PC 与手机应关闭本地 Clash TUN 模式，否则会出现数据包二次套娃导致延迟翻倍且连接数暴涨。

### 局域网共享放行 Windows 防火墙端口与分流验证命令

```powershell
# 以管理员运行 PowerShell，为 Clash 混合端口 7897 放行局域网入站访问（限专用网络）
New-NetFirewallRule -DisplayName "Clash Verge LAN Proxy" -Direction Inbound -Protocol TCP -LocalPort 7897 -Action Allow -Profile Private
```

## 四、「Clash怎么让ChatGPT走指定节点」跨平台部署 FAQ

<details open class="kb-faq-details">
<summary><strong>1. 如何在电脑、手机和路由器之间同步「Clash怎么让ChatGPT走指定节点」的使用体验？</strong></summary>

关键在于选用支持通用订阅的服务商（如 光速云、暮光加速、星岛梦），并在各端统一选用同一内核生态（例如桌面 Clash Verge Rev + 安卓 FlClash + iOS Stash + 软路由 OpenClash/Nikki）。

</details>

<details open class="kb-faq-details">
<summary><strong>2. 仅支持专属客户端的机场怎么在多台设备上保持一致？</strong></summary>

需在每台设备分别安装官方对应系统的专属 App 并登录同一账号，注意 iOS 端可能需要外区商店或 TestFlight，且无法直接在 OpenWrt 软路由上运行。

</details>

<details open class="kb-faq-details">
<summary><strong>3. 为什么我配置了 AI 策略组规则，浏览器访问 Gemini 还是报错？</strong></summary>

检查三件事：① 策略组是否错选成了香港或美国节点（以光速云实测为例，Gemini 需选新加坡/马来/土耳其）；② 浏览器是否开启了自带的“安全 DNS（DoH）”；③ 切完节点后请用无痕窗口清除旧区域 Cookie 再试。

</details>

<details open class="kb-faq-details">
<summary><strong>4. 开启允许局域网连接（Allow LAN）会让外网陌生人连上我的电脑吗？</strong></summary>

只要你的电脑处在家庭路由器内网（NAT 后方），公网无法主动访问你的内网 IP；在公共咖啡厅或酒店 Wi-Fi 下则务必关闭 Allow LAN！

</details>

<details open class="kb-faq-details">
<summary><strong>5. “规则（Rule）”模式和“全局（Global）”模式日常究竟该用哪个？</strong></summary>

99% 的日常时间请锁定在 **规则（Rule）** 模式；只有在极少数冷门海外网站漏出国内分流规则时，才临时切到全局验证。

</details>
