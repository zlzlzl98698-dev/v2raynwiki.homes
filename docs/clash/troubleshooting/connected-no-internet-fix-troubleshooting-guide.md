## 针对「节点超时与连上无网诊断树」的系统级链路排查与日志定位

排查「Clash连接成功但打不开网页怎么办」故障最忌盲目重启电脑或反复重装软件。工程师标准排障思路是严格执行 **从内到外四层隔离法**：

1. **代理端监听确认**：确定客户端核心进程是否成功监听本地端口（如 `127.0.0.1:7897`）。
2. **系统层变量与扩展冲突**：检查浏览器是否装了竞争的 SwitchyOmega / ZeroOmega / 广告拦截代理插件，或 Chrome 开启了「安全 DNS（DoH）」绕过 Fake-IP。
3. **内核日志原文解读**：打开客户端 `Logs（Info 级别）` 观察是否报 `timeout`（入口不可达）、`EOF`（时间差或风控断连）或 `x509`（证书过期/系统日期错误）。
4. **换网交叉验证**：使用手机 4G/5G 热点共享给电脑访问同一节点，若立刻畅通则 100% 为当前宽带/光猫/校园网对特定 UDP 或非标端口限速。

### Windows 退出 Clash 后断网的一键清理恢复命令

```powershell
# 若异常退出导致所有网页报 ERR_PROXY_CONNECTION_FAILED，运行以下两行立即清理系统代理残留
Set-ItemProperty -Path "HKCU:SoftwareMicrosoftWindowsCurrentVersionInternet Settings" -Name ProxyEnable -Value 0
Remove-ItemProperty -Path "HKCU:SoftwareMicrosoftWindowsCurrentVersionInternet Settings" -Name ProxyServer -ErrorAction SilentlyContinue
```

| 日志报错关键词 | 核心触发原因 | 精准排查与修复方案 |
| --- | --- | --- |
| `yaml: line X: could not find expected ':'` | 订阅返回的是 HTML 登录页/拦截页而非合法 YAML | 用浏览器或开启现有备用代理访问订阅 URL 验证返回内容是否有效 |

| `dial tcp ... i/o timeout` | 本地高校校园网/企业网封锁 UDP 或端口，或单个中转节点维护 | 改用标准 TCP 443 端口的 VLESS / Trojan 节点；用手机热点做交叉测试 |

## 五、「Clash连接成功但打不开网页怎么办」故障排查常见问题（FAQ）

<details open class="kb-faq-details">
<summary><strong>1. 遇到「Clash连接成功但打不开网页怎么办」突发异常时，怎么在 1 分钟内判断是本地问题还是机场故障？</strong></summary>

最简单的方法是打开手机关闭 Wi-Fi 改用 5G 移动流量测试同一订阅，或在电脑切换至另一家异构备用订阅：若备用正常而主订阅全红，则为机场侧入口维护；若两个都连不上，则是本地系统代理、时间同步或防火墙冲突。

</details>

<details open class="kb-faq-details">
<summary><strong>2. 修改配置排障后导致客户端彻底无法启动怎么办？</strong></summary>

在客户端 Profiles 目录中关闭或清空刚才修改的全局扩展脚本/Merge 配置，重启内核并重新拉取一次机场原生订阅即可恢复初始状态。

</details>

<details open class="kb-faq-details">
<summary><strong>3. 为什么 Clash 里测速全是绿色 30ms，一开网页就是无法访问？</strong></summary>

90% 是因为 Chrome/Edge 里装了冲突的代理扩展（如 SwitchyOmega 或旧 VPN 插件）把浏览器流量指向了一个已关闭的旧端口（例如 7890），而 Clash Verge Rev 默认端口是 7897。

</details>

<details open class="kb-faq-details">
<summary><strong>4. 提示端口 7897 被占用（bind: address already in use）怎么处理？</strong></summary>

说明后台残留着上一个未退出的 `mihomo.exe` 进程，或者其他软件占用了 7897。打开任务管理器结束残留 mihomo 进程，或者在 Clash 设置里把混合端口改成 `7899` 即可。

</details>

<details open class="kb-faq-details">
<summary><strong>5. 为什么 Microsoft Store、Xbox 应用在开着 Clash 时显示没有网络？</strong></summary>

Windows UWP 沙盒默认禁止访问本机回环地址（127.0.0.1）。在 Clash Verge Rev 设置页打开内置「UWP 工具」，勾选对应应用并点击保存豁免即可。

</details>
