## 针对「Mihomo 新协议支持与流量嗅探」的系统级链路排查与日志定位

排查「Mihomo支持哪些协议」故障最忌盲目重启电脑或反复重装软件。工程师标准排障思路是严格执行 **从内到外四层隔离法**：

1. **代理端监听确认**：确定客户端核心进程是否成功监听本地端口（如 `127.0.0.1:7897`）。
2. **系统层变量与扩展冲突**：检查浏览器是否装了竞争的 SwitchyOmega / ZeroOmega / 广告拦截代理插件，或 Chrome 开启了「安全 DNS（DoH）」绕过 Fake-IP。
3. **内核日志原文解读**：打开客户端 `Logs（Info 级别）` 观察是否报 `timeout`（入口不可达）、`EOF`（时间差或风控断连）或 `x509`（证书过期/系统日期错误）。
4. **换网交叉验证**：使用手机 4G/5G 热点共享给电脑访问同一节点，若立刻畅通则 100% 为当前宽带/光猫/校园网对特定 UDP 或非标端口限速。

### Mihomo 核心 Sniffer 域名嗅探与防 DNS 泄漏推荐配置

```yaml
sniffer:
  enable: true
  parse-pure-ip: true
  sniff:
    HTTP:
      ports: [80, 8080-8880]
    TLS:
      ports: [443, 8443]
dns:
  enable: true
  enhanced-mode: fake-ip
  fake-ip-range: 198.18.0.1/16
  default-nameserver: [223.5.5.5, 119.29.29.29]
  nameserver: ["https://dns.alidns.com/dns-query"]
  fake-ip-filter:
    - "+.lan"
    - "+.local"
    - "time.*.com"
    - "+.ntp.org"
```

## 五、「Mihomo支持哪些协议」故障排查常见问题（FAQ）

<details open class="kb-faq-details">
<summary><strong>1. 遇到「Mihomo支持哪些协议」突发异常时，怎么在 1 分钟内判断是本地问题还是机场故障？</strong></summary>

最简单的方法是打开手机关闭 Wi-Fi 改用 5G 移动流量测试同一订阅，或在电脑切换至另一家异构备用订阅：若备用正常而主订阅全红，则为机场侧入口维护；若两个都连不上，则是本地系统代理、时间同步或防火墙冲突。

</details>

<details open class="kb-faq-details">
<summary><strong>2. 修改配置排障后导致客户端彻底无法启动怎么办？</strong></summary>

在客户端 Profiles 目录中关闭或清空刚才修改的全局扩展脚本/Merge 配置，重启内核并重新拉取一次机场原生订阅即可恢复初始状态。

</details>

<details open class="kb-faq-details">
<summary><strong>3. 开启 Fake-IP 模式后，会影响国内网银、PT 下载或公司内网 VPN 吗？</strong></summary>

大多数常规网页不受影响，但公司私有内网域名（`*.corp`）和 NTP 时间服务器须加入 `fake-ip-filter`；若是高阶 PT 玩家或遇到个别软件异常，可在配置中切换为 `redir-host` 模式测试。

</details>

<details open class="kb-faq-details">
<summary><strong>4. 怎么确认自己的 Clash Verge Rev 正在运行 Mihomo 而不是老版 Clash 内核？</strong></summary>

在软件左侧「设置 → Clash 内核」查看当前勾选状态，正常应显示 `Mihomo`（支持点击右侧刷新按钮在线升级至最新稳定内核）。

</details>

<details open class="kb-faq-details">
<summary><strong>5. DNS 配置里的 default-nameserver 和 nameserver 有什么区别？</strong></summary>

`default-nameserver` 必须填纯 IP（如 `223.5.5.5`），它只干一件事：把 `dns.alidns.com` 这类加密 DoH 域名解析成 IP；随后所有日常域名解析才交给加密的 `nameserver`。

</details>
