# 隐私政策与免责声明

## 一、隐私保护说明

1. **纯静态知识库架构**：本站基于 VitePress 静态生成，不设立用户注册系统，不收集您的姓名、手机号、邮箱密码或支付凭证。
2. **站内搜索数据**：在启用本地中文搜索时，所有检索词均在您的浏览器本地匹配静态索引，不会上传至第三方服务器；若后续切换为 Algolia DocSearch，搜索请求将遵循 Algolia 官方隐私政策。
3. **第三方跳转边界**：点击外部官网或联盟注册链接后，您将离开 `v2raynwiki.homes`，请自行查阅目标服务商的隐私与退款条款。

## 二、免责声明

1. **数据时效性**：网络代理服务商的套餐价格、流量配额、优惠码、节点地区与流媒体/AI 解锁状态随时可能变动。本站所有页面均标明 `核实日期`，购买前请以服务商结算页为准。
2. **实测快照局限**：本站展示的节点测速截图代表特定时间、特定宽带网络环境下的单次快照结果，不构成任何长期稳定性、速度下限或永不失联的保证。
3. **合法合规使用**：本站全部技术文档仅用于网络协议科普、跨平台客户端配置排障与学术/开发网络研究，请严格遵守您所在国家或地区的法律法规。

## 三、外部链接、隐私边界与透明运行规则

1. **推广链接独立隔离属性**：站内所有导向合作服务商注册页的外链统一通过集中配置表渲染，强制附带 `rel="nofollow sponsored noopener"`，既避免向目标商业域名传递非自然推荐权重，也隔离了用户点击后的页面上下文隐私（`noopener`）。
2. **客户端与订阅配置安全指引**：本站所提供的 YAML 示例、全局扩展脚本（Script/Merge）及 PowerShell/Bash 排障命令均只在您的本地终端运行；**v2rayn百科从不代为托管、不收集、也不中转任何用户的个人机场订阅 URL**，请务必妥善保管带有个人身份 Token 的订阅链接，切勿泄露给未知公共在线转换站。
3. **Cookie 与无追踪承诺**：目前版本网站核心阅读与本地检索功能**不挂载任何第三方广告联盟像素（AdSense）、行为画像追踪器或跨站 Cookie**。读者可无顾虑浏览全站技术百科文档与 [客户端官方指南](/clients/)，相关勘误与数据政策亦随时同步于 [关于本站与披露政策](/about/) 及 [搜索维护说明](/about/search-and-maintenance)。
