# 关于 v2rayn百科与商业推广披露

## 一、站点定位

**v2rayn百科（`v2raynwiki.homes`）** 是一个面向中文用户的网络代理技术文档库与机场品牌参数审计数据库。本站聚焦三件具体的事：

1. **把开源代理客户端讲透**：围绕 Clash Verge Rev、v2rayN、Shadowrocket、FlClash、Hiddify 与 OpenWrt 软路由，提供可复现、指向官方渠道的安装、分流与故障排查手册。
2. **把机场品牌参数审清**：对收录的 31 家独立品牌逐项核对计费周期（区分年付折算、月付与不限时包）、客户端限制（区分纯专属客户端与通用订阅）及数据冲突。
3. **把实测证据留档**：保留原始未裁切测试截图、测试时间戳、工具版本及异常低速/失败节点，绝不通过编造数字或删掉差节点美化结论。

## 二、商业推广披露政策

- 本站包含机场品牌的联盟推广注册链接，所有推广链接均集中维护于代码仓库的 `docs/.vitepress/data/links.ts`，并强制添加 `target="_blank" rel="nofollow sponsored noopener"` 属性。
- 当您通过本站链接注册并消费时，本站可能获得一定比例的推广佣金，但**绝不会增加您的实际支付价格**；相关收益用于维持域名、测试环境与内容维护。
- **光速云**为本站优先建设的商业合作专题品牌，因此拥有最完整的深度评测与配套教程入口；但商业合作优先级**绝不伪装为独立无偏排名**，也不改写任何原始测速截图、香港节点 OpenAI 仅限 App、Gemini 区域分化或价格差异提示。

## 三、联系与勘误

如发现品牌价格变更、官网停服跑路、优惠码失效或教程版本过时，欢迎通过 `editorial@v2raynwiki.homes` 发送反馈与截图证据，我们将在核验后更新相应文档的 `updatedDate` 与审计记录。

## 四、评测方法论、证据留档与技术编辑标准（E-E-A-T 说明）

为了让每一份评测结论和排障指引经得起长期交叉检验，**v2rayn百科技术组 / 评测组 / 审计组**在建档与日常维护中执行统一的工程审查规范：

### 1. 数据真实性与可核验分层机制
- **原始实测截图留档（`measured`）**：全站图片中心所展示的 `2026-08-19` 三网 `2Gbps`（长沙电信、广西移动、河北联通）与珠海联通 `9Gbps` 单线程截图，以及 `2026-08-11 MAI-TEST-BOT` 统一测试截图，均**完整保留原图字节并保留顶部与底部环境信息条**（包括客户端版本、测试机房、并发线程数与个别失败/低速异常行）。
- **资料整理与历史边界（`vendor` / `historical`）**：缺乏独立测速截图仅根据服务商公开目录整理的条目，绝不在正文中包装成实测数据；来自 `2026-08-09` 历史归档的品牌强制加注 `historical` 标签，提醒购买前复核。
- **跨文档冲突高亮（`conflict`）**：针对源资料出现多版本优惠码、套餐流量数字矛盾、推广链接路由格式缺失（如云界线、环球梯）或宣传协议与测速图列字段不一致的情况，在对应品牌详情页及 [31 家机场品牌交叉审计摘要](/resources/risk-intel/31-brands-audit-summary) 中逐条公开展示。

### 2. 编辑维护与结构化数据源（GEO / AEO）
- 全站所有品牌数据统一托管于中央仓库结构化源文件，并同步生成面向搜索引擎与大语言模型爬虫的 `/llms.txt` 与 `/brands.json` 数据断点，保证前后端展示、Schema 结构化标记与正文内容严格一致。
- 如对本文档库收录品牌或技术教程有任何勘误建议，可通过官方邮箱反馈，经技术人员复现与核对后将在最近一次迭代周期内更新页面右上角 `核实更新` 时间戳与 `PROGRESS.md` 更新记录。
