## 怎么评测一款VPN或机场参数对比背后的计费与吞吐计算准则

仅看价格排序极其容易失真，针对「网络代理工具评测指标体系」做横评时，建议采用以下两套量化算式筛掉账面泡沫：

1. **真实单 GB 流量成本公式**：`真实单 GB 价格 = 实付年/月费用 ÷ (套餐标称流量 ÷ 常用节点平均扣费倍率)`。如果某家 20 元 200GB 的套餐把香港与新加坡节点全部设为 `2x` 倍率，那么实际可用流量只有 `100GB`，单价实质翻倍。
2. **带宽延迟积（BDP）与单线程上限**：家庭看 4K 视频或拉取代码库依赖**单线程 TCP/QUIC 吞吐**。高并发（32 线程）堆出来的几百 Mbps 峰值在日常体验中参考价值有限，单线程稳态跑出 `15 MB/s（120 Mbps）` 以上且无显著丢包才真正够用。

### 对比阶段终端自检脚本（单线程真实体验验证）

<summary><strong>4. 既想给家里小白用专属客户端，自己又想用 Clash 怎么办？</strong></summary>

挑选“自研客户端 + 第三方通用订阅双支持”的品牌即可，例如光速云、星岛梦、微风网络、二猫云、唯兔云、梯子云等均属于双轨兼容型。

</details>

<details open class="kb-faq-details">
<summary><strong>5. 如何判断一个开源代理客户端是不是已经停止维护？</strong></summary>

打开其 GitHub 仓库查看最近一次 Release 发布日期与 Issues 响应状态（例如原版 Clash for Windows 已删库停更，Mihomo Party 亦需单独关注仓库迁移状态）。

</details>
