## VPN 加速器跨平台底层网络栈与统一规范化策略

Windows（WinHTTP / 注册表代理 / Wintun）、macOS（NetworkExtension / utun）、Android（VpnService 进程锁保活）、iOS（NEPacketTunnelProvider 15MB 内存上限）与 OpenWrt（fw4 nftables + TProxy/TUN）五类环境的底层差异很大，但规则层面应该尽可能集中统一维护。

### 跨终端迁移 4 项工程准则

1. **订阅规则集中托管**：把所有分流规则写入全局可扩展配置或统一远程规则集，不要在 Windows 写一套、到 Shadowrocket 又手工拼凑另一套导致不同步。
2. **注意 iOS 15MB 内存墙限制**：给 iPhone / iPad 配置规则时避免塞入数十万行臃肿的 GEOSITE 全量域名表，优先加载精简后的核心 AI 与流媒体分组列表。
3. **路由器旁路与桌面终端避免双重代理**：当客厅 OpenWrt 已经接管透明代理后，局域网内的 PC 与手机应关闭本地 Clash TUN 模式，否则会出现数据包二次套娃导致延迟翻倍且连接数暴涨。

### 在 Mihomo / Clash Verge Rev 中显式确保 UDP 转发与游戏进程接管

```yaml
# 确保 TUN 开启且系统堆栈使用兼容性最好的 mixed
tun:
  enable: true
  stack: mixed
  auto-route: true
  auto-detect-interface: true
  dns-hijack:
    - "any:53"
```

## 四、「Clash开启TUN模式加速软件」跨平台部署 FAQ

<details open class="kb-faq-details">
<summary><strong>1. 如何在电脑、手机和路由器之间同步「Clash开启TUN模式加速软件」的使用体验？</strong></summary>

关键在于选用支持通用订阅的服务商（如 光速云、暮光加速、一翻云），并在各端统一选用同一内核生态（例如桌面 Clash Verge Rev + 安卓 FlClash + iOS Stash + 软路由 OpenClash/Nikki）。

</details>

<details open class="kb-faq-details">
<summary><strong>2. 仅支持专属客户端的机场怎么在多台设备上保持一致？</strong></summary>

需在每台设备分别安装官方对应系统的专属 App 并登录同一账号，注意 iOS 端可能需要外区商店或 TestFlight，且无法直接在 OpenWrt 软路由上运行。

</details>

<details open class="kb-faq-details">
<summary><strong>3. 在 Clash 节点列表里怎么知道一个节点支不支持游戏联机？</strong></summary>

节点底层配置必须包含 `udp: true`，且实测图中 UDP 类型为 `FullCone` 或 `RestrictedCone`；若写着 `Unknown` 且无法通过 STUN 检测，联机往往受限。

</details>

<details open class="kb-faq-details">
<summary><strong>4. 为什么开了 TUN 模式后，国内软件或 Steam 下载反而变慢了？</strong></summary>

需检查规则中是否把 Steam 下载域名（`steamcontent.com`）与国内网段正确设为 `DIRECT` 直连，切忌在全局（Global）模式下使用游戏加速。

</details>

<details open class="kb-faq-details">
<summary><strong>5. 打竞技类 FPS（如 Valorant / CS2 外服）用机场专线能替代专业游戏加速器吗？</strong></summary>

可以临时救急，但专业游戏加速器针对特定游戏服做过路由静态绑定和丢包重传调优，如果是重度竞技玩家仍建议专款专用。

</details>
